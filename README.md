# QR Code Generator

Генератор QR-кодов с кастомизацией внешнего вида. Electron + Node.js.

Возможности: выбор цвета модулей и фона, уровень коррекции ошибок (L/M/Q/H),
размер 200–1000 px, вставка логотипа в центр, сохранение в PNG.

## Установка и запуск

### Вариант 1: Через терминал (CLI)

npm install
npm start

### Вариант 2: С помощью графического установщика

Запустите файл `QR Code Generator Setup 1.0.0.exe` и следуйте инструкциям на экране.

## Как пользоваться

1. Введите текст или URL в поле «Текст или URL».
2. Настройте цвет модулей и фона, уровень коррекции, размер.
3. При необходимости загрузите логотип (PNG с прозрачностью) и задайте его размер.
4. Нажмите «Сгенерировать» — QR-код появится в области предпросмотра.
5. Нажмите «Сохранить» — выберите папку и имя файла.
